# data-cleaning-project
Transforming a messy multi-table dataset into a structured, analysis ready Power BI data model using Power Query and data modeling principles.
# Overview
This project focuses on transforming a messy multi table dataset into a clean, structured, and analysis ready data model using Power BI and Power Query. The project demonstrates the process of data cleaning, transformation, organization, and data modeling to prepare raw data for analysis and reporting.
# Objective
The main objectives of this project are:
- Clean and transform raw data using Power Query
- Identify and handle data-quality issues
- Organize multiple tables into a structured data model
- Create appropriate relationships between tables
- Prepare the dataset for analysis and reporting in Power BI
- Understand practical data-modeling concepts used in data analytics.
# Tools 
- Power BI
- Power Query
- Data Modeling
- DAX.
# Project Workflow
1. Import the raw dataset into Power BI
2. Examine the structure and quality of the data
3. Clean and transform the data using Power Query
4. Rename and organize tables and columns
5. Handle data types and inconsistencies
6. Create relationships between tables
7. Build a structured data model
8. Prepare the model for analysis and reporting.
